JavaScript Programming & Advisory Engine (Experiment 5)

Interactive execution of variables, operators, decision rules, objects, arrays, and telemetry data processing.

Task 1: Soil Moisture Deficit & Water Requirement Program

Calculates moisture deficit between current telemetry and crop-specific field capacity. Triggers alert() and writes result to DOM.

Task 2: Decision Rule Recommendation Engine

Evaluates multi-variable agronomic rules (Moisture < 30%, 30%-50%, > 50%, and rainfall forecast).

Task 3: Object-Oriented JavaScript — Sugarcane Farm Object

Encapsulates farm attributes (farmerName, plotId, cropStage, soilMoisture, area, pumpStatus) with a member method displayFarmInfo().

Task 4: Hourly Moisture Sensor Telemetry Array Processing

Processes an array of 24 hourly sensor readings: displays all readings, determines minimum, maximum, computes average, and counts readings below critical threshold (<30%).

Task 5: Client-Side Input Validation Functions

Dedicated validation functions for Farmer Name (alphabetical + spaces), Mobile Number (10 digits starting with 6-9), and Plot ID (pattern AGR-####).

Task 6: Interactive Advisory Request & Registration Form

Complete HTML form utilizing semantic controls, DOM event handling, fieldsets, and automated advisory recommendation generation upon valid submission.
