Objectives

The system helps farmers make timely irrigation decisions using AI-based advisory support, continuous soil moisture data, and weather forecasts.

By automating sensor thresholds, the project aims to curtail unnecessary aquifer pumping, optimize cane sugar yield, and prevent both waterlogging and moisture stress.

System Features

It provides crop-wise irrigation guidance, simple alerts, and clear recommendations for farmers, agricultural officers, agronomists, and sugar factory management.

The portal combines easy monitoring, automated advisory notifications, and field-ready scheduling directives in one centralized web platform.

Benefits

This approach saves water, improves crop health, and supports better planning through simple digital advice.

"When irrigation is guided by data, farmers can reduce waste and protect yields."
— Agricultural Expert, Somaiya Center for Agricultural Research

It also supports better coordination between field staff, agricultural universities, and sugar factory command centers.
